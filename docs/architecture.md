# CrisisOps IQ Architecture

- Crisis Reports
- Meeting Notes
- Operational Data
- Policy Documents

↓

## Intake Agent

↓

## Crisis Classifier Agent

↓

↓

↓

## Communications Agent

Generates stakeholder communications.

↓

## Verifier & Safety Agent

Applies safety checks and approval requirements.

↓

Outputs:

- Crisis Summary
- Severity Score
- Root Cause Analysis
- Response Plan
- Human Approval Gates
